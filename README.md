# Zomato Data Analysis 📊

## 📌 Objective
Analyze restaurant data to uncover insights about pricing, ratings, and customer preferences.

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Analysis
- Top cities with most restaurants
- Most popular cuisines
- Cost vs rating relationship
- Online delivery impact

## 🔍 Key Insights
- Most restaurants are concentrated in major cities
- Ratings are generally high (3.5–4.5 range)
- Cost does not strongly affect rating
- Data shows skewness due to high-cost outliers

## 📁 Dataset
Zomato restaurant dataset

## 🚀 Conclusion
This project demonstrates practical data cleaning, analysis, and visualization skills using real-world data.
